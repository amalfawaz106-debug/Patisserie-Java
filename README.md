# 🛒 Supermarket Java Program

This is a simple supermarket system written in Java.

## 💡 Features
- Add items to cart
- Remove items
- Reset cart
- View cart
- Checkout system

## 🧪 Example Usage
Type commands like:

cake  
bread  
remove bread  
show  
checkout  

## 🛠️ How to Run
1. Compile:
   javac Supermarket.java

2. Run:
   java Supermarket
3.initial sync from replit
